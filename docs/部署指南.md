## 1. 服务器准备

### 1.1 购买 ECS

- 规格：2 核 4G 起步（MySQL + PHP-FPM 至少需要这个配置）
- 系统：Ubuntu 22.04 LTS 或 24.04 LTS
- 磁盘：40G+ 系统盘 + 100G 数据盘（可选，用于存上传图片和备份）
- 带宽：按固定带宽 5Mbps 或按量计费

### 1.2 初始化系统

SSH 连接服务器后：

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 创建部署用户（不用 root 部署）
sudo adduser deploy
sudo usermod -aG sudo deploy

# 切换到 deploy 用户操作
su - deploy
```

### 1.3 配置 SSH 密钥登录（禁用密码更安全）

在**本地机器**生成部署密钥对：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/deploy_key -C "deploy@shopping"
```

把公钥上传到服务器：

```bash
ssh-copy-id -i ~/.ssh/deploy_key.pub deploy@你的服务器IP
```

测试免密登录：`ssh -i ~/.ssh/deploy_key deploy@你的服务器IP`

## 2. 安装 LNMP 环境

### 2.1 PHP 8.3

```bash
sudo apt install software-properties-common -y
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install php8.3-fpm php8.3-mysql php8.3-xml php8.3-curl \
    php8.3-mbstring php8.3-zip php8.3-gd php8.3-bcmath php8.3-intl -y
```

验证：`php -v` 应显示 8.3.x

### 2.2 Composer

```bash
curl -sS https://getcomposer.org/installer | sudo php -- --install-dir=/usr/local/bin --filename=composer
composer --version
```

### 2.3 Nginx

```bash
sudo apt install nginx -y
```

### 2.4 MySQL 8

```bash
sudo apt install mysql-server -y
sudo mysql_secure_installation   # 设置 root 密码，移除测试库
```

创建项目数据库和用户：

```bash
sudo mysql
```

```sql
CREATE DATABASE digital_shop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'shopping'@'localhost' IDENTIFIED BY '你的强密码';
GRANT ALL PRIVILEGES ON digital_shop.* TO 'shopping'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

## 3. 首次部署

### 3.1 克隆代码

```bash
sudo mkdir -p /var/www/shopping
sudo chown deploy:deploy /var/www/shopping
cd /var/www
git clone https://github.com/waylanguo-web/Wangzai_Shopping.git shopping
cd shopping
```

### 3.2 安装依赖

```bash
composer install --no-dev --optimize-autoloader
```

### 3.3 配置环境

```bash
cp .env.example .env
php artisan key:generate
nano .env
```

修改 `.env` 关键项：

```env
APP_NAME="Wangzai Shopping"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://你的域名

DB_DATABASE=digital_shop
DB_USERNAME=shopping
DB_PASSWORD=你的数据库密码

MAIL_MAILER=smtp
MAIL_HOST=smtp.qq.com        # 例：QQ 邮箱 SMTP
MAIL_PORT=465
MAIL_USERNAME=你的邮箱@qq.com
MAIL_PASSWORD=你的SMTP授权码
MAIL_ENCRYPTION=ssl
MAIL_FROM_ADDRESS=你的邮箱@qq.com
MAIL_FROM_NAME="${APP_NAME}"
```

### 3.4 初始化数据

```bash
php artisan migrate --force
php artisan db:seed --class=AdminUserSeeder --force
php artisan storage:link
```

### 3.5 缓存优化

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
```

### 3.6 设置权限

```bash
sudo chown -R www-data:deploy /var/www/shopping
sudo chmod -R 775 storage bootstrap/cache
```

> `www-data` 是 Nginx/PHP-FPM 运行用户，`deploy` 是部署用户。
> storage 和 bootstrap/cache 需要 775 让两个用户都能写。

## 4. Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/shopping
```

写入（替换 `你的域名`）：

```nginx
server {
    listen 80;
    server_name 你的域名 www.你的域名;
    root /var/www/shopping/public;
    index index.php index.html;

    charset utf-8;
    client_max_body_size 20M;   # 允许上传大图（凭证/二维码）

    # 日志
    access_log /var/log/nginx/shopping-access.log;
    error_log  /var/log/nginx/shopping-error.log;

    # 主路由
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 禁止访问敏感文件
    location ~ /\.(?!well-known).* { deny all; }
    location ~ ^/(storage|vendor)/ { deny all; }

    # PHP-FPM
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # Livewire 长连接超时
    location = /livewire/livewire.js {
        expires off;
    }
}

# HTTP → HTTPS 重定向（配 SSL 后取消注释）
# server {
#     listen 80;
#     server_name 你的域名 www.你的域名;
#     return 301 https://$server_name$request_uri;
# }
```

启用站点：

```bash
sudo ln -s /etc/nginx/sites-available/shopping /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default
sudo nginx -t          # 测试配置
sudo systemctl reload nginx
```

此时访问 `http://你的域名` 应能看到网站。

## 5. SSL 证书

使用 Let's Encrypt 免费证书，自动续期：

```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d 你的域名 -d www.你的域名
```

按提示输入邮箱、同意条款。完成后：
- Nginx 配置自动加入 443 监听
- 自动设置 HTTP → HTTPS 重定向
- 自动续期定时任务已注册（`sudo certbot renew --dry-run` 测试）

## 6. GitHub Actions 自动部署

实现：`git push origin main` → 自动 SSH 到服务器执行部署。

### 6.1 服务器端准备部署密钥

在**本地机器**生成专用部署密钥（与 1.3 的不同，这个给 GitHub Actions 用）：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/github_deploy -C "github-actions-deploy" -N ""
```

把公钥追加到服务器 deploy 用户的 authorized_keys：

```bash
cat ~/.ssh/github_deploy.pub | ssh -i ~/.ssh/deploy_key deploy@你的服务器IP "cat >> ~/.ssh/authorized_keys"
```

### 6.2 配置 GitHub Secrets

在 GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret：

| Secret 名 | 值 |
|-----------|-----|
| `SERVER_HOST` | 服务器公网 IP |
| `SERVER_USER` | `deploy` |
| `SSH_PRIVATE_KEY` | `github_deploy` 私钥的完整内容（`cat ~/.ssh/github_deploy`） |
| `DEPLOY_PATH` | `/var/www/shopping` |

### 6.3 创建 Workflow 文件

在项目根目录创建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy to Production

on:
  push:
    branches: [main]

jobs:
  deploy:
    name: Deploy
    runs-on: ubuntu-latest
    steps:
      - name: SSH Deploy
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          script_stop: true
          script: |
            cd ${{ secrets.DEPLOY_PATH }}
            git pull origin main
            composer install --no-dev --optimize-autoloader
            php artisan migrate --force
            php artisan config:cache
            php artisan route:cache
            php artisan view:cache
            php artisan event:cache
            sudo systemctl reload php8.3-fpm
            sudo systemctl reload nginx
```

> `script_stop: true` 表示任一命令失败即终止部署。

### 6.4 服务器 sudo 免密（仅 reload）

GitHub Actions 用 deploy 用户执行，需要允许 deploy 免密 reload 服务：

```bash
sudo visudo
```

在文件末尾追加：

```
deploy ALL=(ALL) NOPASSWD: /usr/bin/systemctl reload php8.3-fpm, /usr/bin/systemctl reload nginx
```

### 6.5 推送测试

```bash
git add .github/workflows/deploy.yml
git commit -m "ci: add GitHub Actions auto deploy"
git push origin main
```

去 GitHub 仓库 → Actions 标签页，应看到 Deploy 工作流运行，绿色 ✓ = 部署成功。

### 6.6 分支策略

| 分支 | 用途 | 部署 |
|------|------|------|
| `main` | 生产环境 | push 自动部署 |
| `dev` | 开发测试 | 不自动部署，本地 `php artisan serve` 测试 |

工作流：在 `dev` 开发 → 本地测试通过 → 提 PR `dev → main` → 合并即上线。

## 7. 防火墙与安全

### 7.1 阿里云安全组

仅开放：

| 端口 | 用途 | 来源 |
|------|------|------|
| 22 | SSH | 限你的 IP（或 GitHub Actions IP） |
| 80 | HTTP | 0.0.0.0/0 |
| 443 | HTTPS | 0.0.0.0/0 |

### 7.2 服务器防火墙

```bash
sudo ufw allow 22
sudo ufw allow 80
sudo ufw allow 443
sudo ufw enable
```

### 7.3 SSH 加固

编辑 `/etc/ssh/sshd_config`：

```
PermitRootLogin no           # 禁止 root 登录
PasswordAuthentication no    # 禁止密码登录（仅密钥）
```

```bash
sudo systemctl restart sshd
```

### 7.4 修改管理员密码

首次部署后立即登录后台 `/admin/dashboard`，在「个人资料」修改默认密码 `admin123`。

## 8. 数据库备份

### 8.1 自动备份脚本

```bash
sudo nano /usr/local/bin/backup-db.sh
```

```bash
#!/bin/bash
BACKUP_DIR=/var/backups/mysql
DATE=$(date +%F)
mkdir -p $BACKUP_DIR
mysqldump -u shopping -p'你的数据库密码' digital_shop | gzip > $BACKUP_DIR/digital_shop_$DATE.sql.gz
# 保留最近 30 天
find $BACKUP_DIR -name "digital_shop_*.sql.gz" -mtime +30 -delete
```

```bash
sudo chmod +x /usr/local/bin/backup-db.sh
sudo crontab -e
```

添加（每天凌晨 3 点备份）：

```
0 3 * * * /usr/local/bin/backup-db.sh
```

### 8.2 阿里云 RDS（可选）

如果用阿里云 RDS 替代自建 MySQL，开启自动备份 + 跨可用区容灾，更省心但费用更高。

## 9. 日常维护

### 9.1 查看日志

```bash
# Laravel 应用日志
tail -f /var/www/shopping/storage/logs/laravel.log

# Nginx 访问/错误日志
tail -f /var/log/nginx/shopping-access.log
tail -f /var/log/nginx/shopping-error.log

# PHP-FPM 日志
tail -f /var/log/php8.3-fpm.log
```

### 9.2 日志轮转（防止日志撑满磁盘）

```bash
sudo nano /etc/logrotate.d/shopping
```

```
/var/www/shopping/storage/logs/*.log {
    daily
    rotate 14
    compress
    delaycompress
    missingok
    notifempty
    create 644 www-data deploy
}
```

```bash
sudo logrotate -f /etc/logrotate.d/shopping   # 立即测试
```

### 9.3 磁盘空间监控

```bash
df -h    # 查看磁盘使用
du -sh /var/www/shopping/storage/app/public/*   # 查看上传图片占用
```

### 9.4 更新依赖

```bash
cd /var/www/shopping
composer update --no-dev
composer audit   # 检查已知漏洞
php artisan config:cache && php artisan route:cache
```

> 建议先在 `dev` 分支本地测试 `composer update`，通过后再合并 `main` 自动部署。

### 9.5 同步上游更新（可选）

如果想拉取原作者的更新：

```bash
git fetch upstream
git merge upstream/main    # 或 git rebase upstream/main
# 解决冲突后
git push origin main       # 自动部署
```

## 10. 故障排查

### 502 Bad Gateway

PHP-FPM 没运行或 socket 不匹配：

```bash
sudo systemctl status php8.3-fpm
sudo systemctl restart php8.3-fpm
# 确认 Nginx 配置里 fastcgi_pass 路径与实际 socket 一致
ls /run/php/
```

### 500 Internal Server Error

查看 Laravel 日志：

```bash
tail -50 /var/www/shopping/storage/logs/laravel.log
```

常见原因：`.env` 配置错、权限不足、migration 没跑。

### 图片显示 404

storage 软链接丢失：

```bash
cd /var/www/shopping
php artisan storage:link
```

### 部署后白屏

缓存没刷新或权限问题：

```bash
php artisan optimize:clear
sudo chown -R www-data:deploy storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache
```

### GitHub Actions 部署失败

1. 去 GitHub → Actions 查看失败步骤的日志
2. 常见原因：
   - SSH 连接失败 → 检查 `SERVER_HOST`、`SSH_PRIVATE_KEY`、服务器 authorized_keys
   - `git pull` 冲突 → 服务器有本地改动，SSH 上去 `git status` 查看，`git stash` 或 `git reset --hard origin/main`
   - `composer install` 失败 → PHP 版本/扩展缺失
   - `migrate` 失败 → 数据库连接或 SQL 语法问题，查 laravel.log

### 数据库连接失败

```bash
mysql -u shopping -p -e "SHOW DATABASES;"   # 测试连接
# 确认 .env 的 DB 配置与实际一致
php artisan config:clear   # 可能是缓存了旧配置
php artisan config:cache
```

## 快速部署清单（精简版）

已有服务器 SSH 权限时，按顺序执行：

```bash
# 1. 装环境
sudo apt update && sudo apt install -y nginx mysql-server php8.3-fpm php8.3-mysql php8.3-xml php8.3-curl php8.3-mbstring php8.3-zip php8.3-gd
curl -sS https://getcomposer.org/installer | sudo php -- --install-dir=/usr/local/bin --filename=composer

# 2. 建库
sudo mysql -e "CREATE DATABASE digital_shop CHARACTER SET utf8mb4; CREATE USER 'shopping'@'localhost' IDENTIFIED BY '密码'; GRANT ALL ON digital_shop.* TO 'shopping'@'localhost';"

# 3. 拉代码
cd /var/www && git clone https://github.com/waylanguo-web/Wangzai_Shopping.git shopping && cd shopping
composer install --no-dev --optimize-autoloader
cp .env.example .env && php artisan key:generate
# 编辑 .env（DB、MAIL、APP_URL）
php artisan migrate --force && php artisan db:seed --class=AdminUserSeeder --force
php artisan storage:link && php artisan config:cache && php artisan route:cache && php artisan view:cache

# 4. 权限
sudo chown -R www-data:www-data /var/www/shopping && sudo chmod -R 775 storage bootstrap/cache

# 5. Nginx + SSL（按第 4、5 节配置）
# 6. 配 GitHub Actions（按第 6 节）
```
